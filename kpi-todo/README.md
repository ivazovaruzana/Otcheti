# KPI To-Do

Одностраничное приложение для личных KPI-целей на полугодие: список целей,
раскрытие цели, отметка выполненных подзадач, добавление и удаление подзадач
и целей, календарь сроков.

Данные хранятся в localStorage браузера. Сервера и авторизации нет.

## Что в проекте

- `CLAUDE.md` — правила работы над проектом.
- `AGENTS.md` — те же правила для независимой проверки.
- `data/kpi_h2_2026.json` — рабочий набор: снимок KPI-целей из Jira
  (подзадачи контейнера KPI-29563), загружается при первом запуске. Дата
  снимка — в поле `source.fetchedAt` и на бейдже в шапке.
- `data/kpi_h2_demo.json` — вымышленный образец формата, в приложение не
  загружается.
- `src/` — приложение: React + Vite.
  - `lib/goals.js` — чистые функции правок над списком целей.
  - `lib/storage.js` — чтение и запись localStorage.
  - `lib/dates.js` — месяцы полугодия, сетка календаря, формат дат.
  - `components/` — список целей, формы, календарь, переключатель периода.

## Что нужно для запуска

Node.js 18 или новее вместе с npm. Проверить:

```bash
node -v
```

## Как запустить

```bash
npm install
npm run dev
```

Открыть адрес, который покажет Vite — обычно http://localhost:5173

Сборка и просмотр собранной версии:

```bash
npm run build
npm run preview
```

## Как проверить

1. **Список.** Открыть страницу — слева четыре цели на H2 2026 (КВЦ, Система
   управления временем, Агенты Банки.ру, Умный офис) со счётчиком подзадач,
   справа календарь июль – декабрь. Сроков в Jira нет, поэтому у целей
   «срок не задан», календарь пуст, пока сроки не проставлены в приложении.
   Переключить на H1 2026 — пустое состояние «На H1 2026 целей нет».
2. **Детали.** Раскрыть «Система управления временем» — строка со ссылкой на
   задачу Jira и статусом, описание, четыре подзадачи-шага. Длинные названия
   шагов переносятся, вёрстка не ломается. Раскрыть «КВЦ» — «Без описания»
   и «Подзадач пока нет».
3. **Редактирование.** Отметить подзадачу — счётчик меняется. Добавить
   подзадачу через форму внизу цели, удалить её крестиком. Кнопкой
   «+ Новая цель» добавить цель, кнопкой «Удалить цель» удалить её —
   с подтверждением.
4. **Сохранение.** Сделать любую правку и перезагрузить страницу — правка
   на месте.

## Где лежат данные и как их сбросить

Правки — в localStorage под ключом `kpi-todo.goals.v2`. Чтобы вернуться к
снимку из `data/kpi_h2_2026.json`: инструменты разработчика → Application →
Local Storage → удалить этот ключ → перезагрузить страницу.

Обновить снимок из Jira: запросить `parent = KPI-29563` через MCP
`banki-jira` (только чтение) и переписать `data/kpi_h2_2026.json`, затем
сбросить localStorage как описано выше — иначе приложение продолжит
показывать старые правки.

Если запись под ключом повреждена, приложение загружает снимок из файла, а
повреждённую копию откладывает под ключом `kpi-todo.goals.v2.corrupted`.
Данные старой версии (`kpi-todo.goals.v1`, там был демо-набор) удаляются
автоматически при первом запуске.
Если сохранить изменения не удалось (переполнено хранилище, приватный
режим), над списком появится предупреждение.

## Ограничения

- Jira — только чтение, снимок обновляется вручную; приложение в сеть не ходит.
- Другие внешние сервисы (n8n, Loop и т. п.) не подключаются.
- Секреты и токены в проекте не хранятся: токен Jira — в Windows Credential
  Manager.
